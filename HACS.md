# Installation with HACS

Add https://github.com/xsiimonox/caperplus-home-assistant to HACS as a custom integration:

1. HACS → Integrations → menu → Custom repositories.
2. Enter the GitHub repository URL and select **Integration**.
3. Find **CaperPlus Cloud**, install it, and restart Home Assistant.
4. Add **CaperPlus Cloud** under Settings → Devices & services.

Manual installation is described in `README.md`.
